# MATTER-0001: OURSELF Matter Compiler Contract

## Purpose

The Matter Compiler is itself typed, versioned, addressable Matter. It transforms a semantic object into executable, validated Matter without erasing provenance or prior states.

## Canonical identity

- matter_id: MATTER-0001
- matter_type: COMPILER
- name: OURSELF Matter Compiler
- version: 0.1.0
- jurisdiction.reality: OURSELFECOSYSTEM
- jurisdiction.instance: ALTONUMBUSELF
- substrate: GitHub

## Pipeline

DISCOVER → IDENTIFY → HASH_PREIMAGE → PARSE → TYPE → NORMALIZE → RESOLVE_DEPENDENCIES → FORMALIZE → BIND_ALGORITHM_FORMULA → CONSTRUCT_STATE_MACHINE → VALIDATE → GENERATE_EXECUTABLE_MATTER → GENERATE_EVIDENCE_PLAN → GENERATE_RECEIPT_PLAN → ADMIT → ACTUATE → RECONTACT → OBSERVE → RECEIPT → REGISTER

## State lineage

M0 PREIMAGE → M1 PARSED → M2 TYPED → M3 NORMALIZED → M4 FORMAL → M5 COMPILED → M6 VALIDATED → M7 ADMITTED → M8 ACTUATED → M9 OBSERVED → M10 RECEIPTED

These are historical states, not a claim that execution implies observation or observation implies admission.

## Orthogonal facts

AUTHORITY, CAPABILITY, PREIMAGE, ADMISSION, ACTUATION, EXECUTED, OBSERVED, WITNESSED, RECEIPTED, and RECONTACTED are independently represented facts.

## Required invariants

- NO MATTER WITHOUT TYPE
- NO EXECUTABLE MATTER WITHOUT ALGORITHM
- NO FORMULA WITHOUT PROVENANCE
- NO TRANSITION WITHOUT CONTRACT
- NO ACTUATION WITHOUT ADMISSION
- NO CLAIM OF EFFECT WITHOUT OBSERVATION
- NO RECEIPT WITHOUT OBSERVED ARTIFACT
- NO RECONTACT WITHOUT READING EXTERNAL STATE
- OBSERVATION ≠ ADMISSION
- OBSERVATION ≠ AUTHORITY
- OBSERVATION ≠ MUTATION
- EXECUTION ≠ OBSERVATION

## Formalization rule

FORMALIZATION ≠ INVENTION.

When source matter has no defensible mathematical definition, the compiler MUST represent it as UNFORMALIZED or BLOCKED rather than inventing a formula.

## Migration safety

The compiler MUST NOT mark ecosystem Matter as migrated merely because a source artifact was discovered, parsed, copied, or compiled. Migration requires the declared admission, actuation, external observation, receipt, and registration predicates for the target state.

## Rollback

This contract is additive. Removing the branch or reverting its commit(s) restores the prior repository state. No ecosystem Matter is modified by this contract alone.
