# MORPH-X: Minimum Viable OURSELF Matter Compiler Contract

## Acceptance predicate

PASS iff:

- schemas/matter.schema.json exists
- schemas/transition.schema.json exists
- schemas/formula.schema.json exists
- schemas/receipt.schema.json exists
- compiler contract exists
- compiler has canonical Matter identity
- registry exists
- SELFGraph can represent compiler lineage
- no ecosystem Matter is falsely declared migrated

## Proving specimen

SELFMOAT is the first deliberately small Matter to compile.

The specimen MUST exercise semantic type, invariant, authority, admission, transition, refusal, quarantine, evidence, receipt, and recontact.

## Scope boundary

MORPH-X does not mass-import ecosystem Matter.

No existing ecosystem concept is declared migrated by the existence of these artifacts.
